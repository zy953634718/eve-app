# 接线表 · 树莓派 5

> 照表接，接完用 `i2cdetect -y 1` 和 `gpio readall` 对一遍再通电。

---

## 一、电源分配（最先做，做错烧板）

```
                        ┌──────────────────────────┐
   12V 锂电 10Ah ───────┤ BMS 保护板                │
                        └────┬─────────────────────┘
                             │
        ┌────────────────────┼────────────────────┐
        │                    │                    │
   ┌────▼─────┐        ┌─────▼──────┐      ┌──────▼──────┐
   │电机驱动   │        │DC-DC 12→5V │      │DC-DC 12→6V  │
   │VM 12V    │        │5A          │      │3A           │
   └──────────┘        └─────┬──────┘      └──────┬──────┘
                             │                    │
                       树莓派 5V(GPIO 2/4)   PCA9685 V+ / 舵机
```

**三条不能违反的规则：**

1. **舵机独立 6V 供电**，绝对不能从树莓派 5V 取。堵转瞬间 2A，树莓派会重启
2. **共地必须做**。树莓派 GND、电机驱动 GND、两个 DC-DC 的 GND，全部连一起
3. **电机驱动前加 1000μF 电解电容**，吸收启停浪涌

## 三、I2C 地址对照

上电后跑 `i2cdetect -y 1`，应该看到：

| 地址 | 设备 |
|---|---|
| `0x40` | PCA9685（舵机驱动） |
| `0x68` | MPU6050（IMU） |
| `0x6A` 或 `0x6B` | 部分 ReSpeaker 型号 |

**看不到设备怎么办：**
1. `raspi-config` → Interface → I2C → Enable
2. 检查 SDA/SCL 是否接反（最常见）
3. 用 `i2cdetect -y 0` 试另一个 I2C 总线（树莓派 5 有两条）

| 3 | 左臂肘 | 90°±40° | 50°-130° |
| 4 | 右臂肩 | 90°±45° | 45°-135° |
| 5 | 右臂肘 | 90°±40° | 50°-130° |

> ⚠️ **限幅必须写死。** 装之前先手动试出机械极限，再在代码里留 5° 余量。舵机顶到机械限位会烧。

## 五、通电检查顺序

**别一次全通电，按顺序来：**

```
第 1 步：只接 12V 电池，量 BMS 输出是否 12V
        ✅ 正常 → 继续  ❌ 异常 → 查 BMS

第 2 步：接 DC-DC，量 5V 和 6V 输出
        ✅ 5V±0.2 / 6V±0.2 → 继续

第 3 步：只接树莓派，正常开机
        ✅ 看到桌面 → 继续

第 4 步：接 I2C 设备，跑 i2cdetect
        ✅ 看到 0x40 和 0x68 → 继续

第 5 步：接舵机，用 PCA9685 单独测每个通道
        ✅ 每个都能转 → 继续

第 6 步：最后接电机，**先垫高离地**再通电
        ✅ 四轮能转 → 落地测试
```

**每一步不通过就停下来查，别抱着"应该没事"往下接。** 烧树莓派的 ¥600 是小事，烧了之后排查三天才是真浪费。
