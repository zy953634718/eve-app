## 二、阶段 P1：底盘与结构（第 1-3 周）

**目标：站得稳、走得动、推不倒。**

### 步骤 1.1 — 定尺寸与建模（3-4 天）

```
整机尺寸：340 × 300 × 420 mm（宽 × 深 × 高）
重量分配：底盘 55% / 躯干 25% / 头部 20%
重心位置：距地 90mm，位于底盘几何中心偏后 10mm
```

- 三段式结构：头部（可拆）→ 躯干（电子仓）→ 底盘（动力 + 电池）
- **重心越低越好。** 电池装在最底层，这是天然的配重
- 底盘轮距 ≥ 240mm，轴距 ≥ 200mm，否则转弯容易侧翻

### 步骤 1.2 — 打印结构件（5-7 天）

| 参数 | 值 | 说明 |
|---|---|---|
| 材料 | PETG | PLA 脆，撞一下就裂 |
| 壁厚 | 2.4mm | 受力件加到 3.6mm |
| 填充 | 20% 网格 | 轮座、电机支架用 40% |
| 层高 | 0.2mm | 强度与速度平衡 |

**打印件清单**：底盘主壳、裙边 ×2、轮座 ×4、电机支架 ×2、电池仓、躯干框架、头部外壳 ×2、颈关节件

> ⚠️ 裙边要做**柔性件**——用 TPU 打印，或者直接买橡胶条裁。这是防夹手的关键，硬质裙边等于没做。

### 步骤 1.3 — 装动力系统（3-4 天）

接线顺序，照着来：

```
电池 12V ──┬── 电机驱动 VM
           ├── DC-DC ── 5V ── 树莓派
           └── DC-DC ── 6V ── 舵机（独立供电！）

树莓派 GPIO ── 电机驱动逻辑引脚
树莓派 GPIO ── PCA9685 ── 舵机
```

**关键：舵机电源必须和树莓派分开。** 舵机堵转电流能到 2A，共电源会导致树莓派重启。

先写最简控制脚本验证：

```python
# motor_test.py — 跑通四轮正反转
import RPi.GPIO as GPIO
import time

# 引脚定义（按实际接线改）
PINS = {"fl": (17, 18), "fr": (22, 23), "rl": (24, 25), "rr": (5, 6)}

def setup():
    GPIO.setmode(GPIO.BCM)
    for fwd, bwd in PINS.values():
        GPIO.setup(fwd, GPIO.OUT)
        GPIO.setup(bwd, GPIO.OUT)

def wheel(key, speed=1):
    """speed: 1 正转 / -1 反转 / 0 停"""
    fwd, bwd = PINS[key]
    GPIO.output(fwd, speed > 0)
    GPIO.output(bwd, speed < 0)

def stop_all():
    for k in PINS:
        wheel(k, 0)

if __name__ == "__main__":
    setup()
    try:
        for k in PINS:
            print(f"测试 {k}")
            wheel(k, 1); time.sleep(1)
            wheel(k, -1); time.sleep(1)
            wheel(k, 0); time.sleep(0.5)
    finally:
        stop_all()
        GPIO.cleanup()
```

```python
# face_track.py — 人脸检测 + 云台跟随
import cv2
import mediapipe as mp
import time

mp_face = mp.solutions.face_detection
detector = mp_face.FaceDetection(model_selection=0, min_detection_confidence=0.6)

cap = cv2.VideoCapture(0)
cap.set(cv2.CAP_PROP_FRAME_WIDTH, 640)
cap.set(cv2.CAP_PROP_FRAME_HEIGHT, 480)

# 平滑参数：越小越稳但越迟钝
SMOOTH = 0.25
prev_x, prev_y = 0.5, 0.5

while True:
    ok, frame = cap.read()
    if not ok:
        continue

    frame = cv2.flip(frame, 1)          # 镜像，符合直觉
    rgb = cv2.cvtColor(frame, cv2.COLOR_BGR2RGB)
    result = detector.process(rgb)

    if result.detections:
        box = result.detections[0].location_data.relative_bounding_box
        cx = box.xmin + box.width / 2
        cy = box.ymin + box.height / 2

        # 指数平滑，避免舵机抖动
        prev_x = prev_x * (1 - SMOOTH) + cx * SMOOTH
        prev_y = prev_y * (1 - SMOOTH) + cy * SMOOTH

        # 转成舵机角度
        pan = (prev_x - 0.5) * 180        # 左右
        tilt = (0.5 - prev_y) * 60        # 上下

        print(f"人脸 ({cx:.2f},{cy:.2f}) → 云台 pan={pan:.0f} tilt={tilt:.0f}")
        # TODO: 接到 PCA9685 驱动舵机

    time.sleep(0.03)                     # 约 30fps
```

### 步骤 2.3 — 表情动作库（3-4 天）

三组基础动作，后面所有交互都靠它们组合：

| 动作 | 实现 | 情绪含义 |
|---|---|---|
| 眨眼 | 眼部 LED 短灭 80ms | 活力、聆听中 |
| 注视 | 云台锁定人脸，偏移 0 | 专注、被关注 |
| 歪头 | pan+5°, tilt+8° 保持 400ms | 好奇、疑惑 |

> 💡 **行为节奏比动作本身重要。** 同样一个转头，用 0.8s 匀速转和"先快后慢 + 到位微调"是两种完全不同的生命感。后者才像活物。

```python
# asr.py — 录音 + 本地转写
import subprocess
import tempfile
import wave
import numpy as np
import pyaudio
import webrtcvad          # VAD 做端点检测，避免录固定时长

def record_until_silence(max_sec=8, silence_ms=800):
    """录到用户停顿就停，不用录满固定时长。"""
    p = pyaudio.PyAudio()
    stream = p.open(format=pyaudio.paInt16, channels=1,
                    rate=16000, input=True, frames_per_buffer=480)
    frames, silent, started = [], 0, False

    for _ in range(int(16000 / 480 * max_sec)):
        data = stream.read(480, exception_on_overflow=False)
        energy = np.abs(np.frombuffer(data, dtype=np.int16)).mean()

        if energy > 400:          # 有声音
            started = True
            silent = 0
            frames.append(data)
        elif started:
            silent += 1
            frames.append(data)
            if silent * 480 / 16000 * 1000 > silence_ms:
                break

    stream.stop_stream(); stream.close(); p.terminate()

    tmp = tempfile.NamedTemporaryFile(suffix=".wav", delete=False)
    with wave.open(tmp.name, "wb") as w:
        w.setnchannels(1); w.setsampwidth(2); w.setframerate(16000)
        w.writeframes(b"".join(frames))
    return tmp.name


def transcribe(wav_path: str) -> str:
    import os
    out = wav_path + ".txt"
    subprocess.run([
        os.path.expanduser("~/whisper.cpp/main"),
        "-m", os.path.expanduser("~/whisper.cpp/models/ggml-small.bin"),
        "-f", wav_path,
        "-l", "zh",            # 中文
        "-otxt",               # 输出文本
        "--no-timestamps",
    ], check=True, capture_output=True)

    with open(out, encoding="utf-8") as f:
        return f.read().strip()
```

完整链路串联（**这是主程序**）：

```python
# main_voice.py — 五段链路串联
import time
from dialogue_core import Conversation, stream_reply, is_safe, SAFE_FALLBACK
from asr import record_until_silence, transcribe
import subprocess

def speak(text: str):
    """Piper 合成 + 播放。"""
    subprocess.run(
        ["piper", "--model", "zh_child.onnx", "--output_file", "say.wav"],
        input=text.encode("utf-8"), check=True,
    )
    subprocess.run(["aplay", "-q", "say.wav"], check=True)


def main():
    conv = Conversation()
    print("瓦力已启动，说唤醒词开始对话。")

    while True:
        # ① 等唤醒（这里简化成阻塞，实际应独立线程常驻监听）
        wait_for_wake()

        # ② 录音 + 转写
        t0 = time.time()
        wav = record_until_silence()
        user_text = transcribe(wav)
        t_asr = time.time() - t0

        if not user_text or not is_safe(user_text):
            speak(SAFE_FALLBACK if user_text else "我没听清呀，再说一次好不好？")
            continue

        print(f"[转写 {t_asr:.2f}s] {user_text}")
        conv.add_user(user_text)

        # ③ 流式拿回复，④ 按句合成播报
        t1 = time.time()
        first = True
        for sentence in stream_reply(conv):
            if first:
                print(f"[首句延迟 {time.time()-t1:.2f}s]")
                first = False
            speak(sentence)

        print(f"[本轮总耗时 {time.time()-t0:.2f}s]\n")


if __name__ == "__main__":
    main()
```

**importance 分级标准**（这是最需要产品判断的地方）：

| 分值 | 判断标准 | 例子 |
|---|---|---|
| 5 | 持续影响，永远该记 | 最喜欢的恐龙品种 |
| 4 | 长期特征 | 有妹妹、每天八点来聊天 |
| 3 | 值得记一段时间 | 上周去了动物园 |
| 2 | 短期有效 | 今天有点感冒 |

### 步骤 4.3 — 召回注入（2-3 天）

在 `dialogue_core.py` 的 `messages()` 里加一段：

```python
def messages(self):
    memory_block = store.recall_as_prompt(limit=8)   # 只带 8 条
    system = SYSTEM_PROMPT
    if memory_block:
        system += "\n\n" + memory_block
    return [{"role": "system", "content": system}, *self.history]
```

> 💡 **控额度是关键。** 记忆不是越多越好，每轮都塞 50 条记忆会：① token 费用翻倍；② 模型注意力被稀释，反而答得更差。8 条是实测的甜点。
